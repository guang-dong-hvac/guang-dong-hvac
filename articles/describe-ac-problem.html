报修指南 · 空调

空调坏了，怎么跟师傅描述？记住这 5 点

一个电话能不能约对师傅、带对配件，就看你说得清不清楚。记住下面 5 点——不是让你自己诊断，是让林生在电话里判断个大概、带齐东西上门，一次修好。

1. 冰不冰

这是最重要的一句。说清楚：完全不凉，还是有点凉但不给力，还是时凉时不凉？开了多久才发现的？——"冰不冰"直接决定师傅先查雪种还是先查电路。

2. 有没有结霜、结冰

看一眼室内机和室外机：铜管上有没有白霜，室内机有没有结冰、滴水？结霜多半是雪种不够或滤网太脏，这是很有价值的一条信息。

3. 漏不漏水、哪里漏

漏水要说清哪里漏：是室内机往下滴水，还是墙上有水渍，还是室外机下面一滩水？大概什么位置、漏得厉害吗？不同位置漏水，原因完全不一样。

4. 有没有什么异常

有没有异响（什么样的响：嗡嗡、咔哒、呼呼）？有没有异味？有没有跳电？遥控器有没有反应？这些细节能帮师傅排除一大半可能。

5. 机器的基本信息

什么牌子、用了几年、是中央空调还是分体/窗机？牌子型号在机器侧面铭牌上，拍张照片最省事。

描述清楚，对你有什么好处

说清楚故障，师傅出门就带对配件、带对工具，一趟搞定，不用跑两趟——省的是你的时间和上门费。另外提醒一句：别自己拆机、别自己加雪种。雪种要专业设备抽真空、定量加，加多加少都伤机器；自己动过的地方，师傅反而更难判断，有时候越弄越贵。

  • 冰不冰：不凉 / 不太凉 / 时凉时不凉
  • 结霜：有 / 没有，在哪个位置
  • 漏水：漏 / 不漏，哪里漏、漏得厉害吗
  • 异常：异响 / 异味 / 跳电 / 遥控器没反应
  • 机器：牌子、用了几年、中央/分体/窗机
